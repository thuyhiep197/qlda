# Dữ liệu đơn vị hành chính (Danh mục địa chính)

vn-admin-units.json: 34 tỉnh/thành phố và 3.321 phường/xã/đặc khu, rút gọn từ
https://github.com/ThangLeQuoc/vietnamese-provinces-database (json/vn_only_simplified_json_generated_data_vn_units.json, bản v5.2.0, cập nhật theo 388/NQ-UBTVQH16).
Chỉ dùng để nạp sẵn khi CSDL chưa có danh mục; sau đó quản trị viên sửa trên màn hình Danh mục địa chính.
